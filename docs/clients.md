# ACP clients

NanoBird is an ACP agent. Any client that launches external ACP agents can run `nanobird acp` as its command (SPEC §8, §11.2). The architecture figure (SPEC §3) lists Zed, JetBrains, Neovim and Toad.

Setup notes for each client are written with stage 2, when the ACP adapter exists (see [ROADMAP.md](ROADMAP.md)).
